# BlokSchool Competitive Analysis: Platform Gaps & Opportunities

**Date:** March 18, 2026
**Purpose:** Identify what existing education/course platforms do NOT provide, and define actionable features that differentiate BlokSchool for coding/AI education.

---

## PLATFORM-BY-PLATFORM ANALYSIS

---

### 1. SKOOL (skool.com)

**What it offers:** Community-first platform with discussion feeds, gamification (leaderboards/points), basic course hosting, events calendar, direct messaging.

**What it's MISSING or does poorly:**
- No native video hosting (must embed from YouTube/Vimeo/Loom)
- No quizzes, assessments, or certificates
- No drip content scheduling
- Cannot bold/italicize text in the editor (no rich text)
- Cannot upload PDFs or downloadable resources directly
- No private channels or group chats (only public posts + 1:1 DMs)
- No post scheduling
- No email broadcasts or automation (requires ConvertKit/Mailchimp externally)
- No custom domain support
- No funnel builder or sales pages
- Single-feed structure with no segmentation or sub-groups
- Extremely limited customization (icon, cover photo, light/dark mode only)
- No API or developer tools

**What users complain about:**
- $9/mo plan has a 10% transaction fee (highest in the industry)
- Billing/cancellation issues with unresponsive support
- Login process confusion for non-technical members
- Feels "overhyped" relative to actual feature depth
- No advanced LMS features whatsoever

**Pricing:** $9/mo (Hobby, 10% transaction fee) or $99/mo (Pro, 0% fee)

---

### 2. TEACHABLE (teachable.com)

**What it offers:** Course hosting, basic quizzes, sales pages, payment processing, coaching products, affiliate marketing.

**What it's MISSING or does poorly:**
- Quizzes limited to basic multiple-choice or short answer; no question banks, randomization, or file upload questions
- No community features built-in
- Limited marketing tools (fallen behind competitors)
- Clunky, slow-loading sales page builder
- No advanced assessment types
- No interactive or hands-on coding exercises
- No student collaboration tools

**What users complain about:**
- May 2025 pricing restructure caused massive backlash: hard product limits, student caps, forced migrations
- 7.5% transaction fee on Starter plan ($29/mo)
- Free plan eliminated in 2025
- Users report being charged after cancellation (ongoing for months)
- Revenue held without explanation or communication
- Customer support is slow, uses obscure ticket system, often ignores users
- Prices have doubled or tripled for long-time users (7-year user went from $119/mo to $309/mo)
- Product limits force deletions or expensive upgrades (Starter: 1 product, 100 students max)

**Pricing:** $29/mo Starter (7.5% fee, 1 product, 100 students) to $665/mo Enterprise

---

### 3. KAJABI (kajabi.com)

**What it offers:** All-in-one: courses, website builder, email marketing, landing pages, pipelines/funnels, podcasts, coaching, community, automations.

**What it's MISSING or does poorly:**
- No native Zoom integration in community
- No gamification
- Limited moderation tools
- Cannot embed discussions directly into course lessons
- Members cannot add multiple pictures to posts
- Course platform described as "incredibly limited" relative to the rest of the platform
- No advanced assessments, question banks, SCORM, or interactivity
- Limited design customization; cannot add plugins or deeply customize blocks
- No multi-site support below Pro plan
- No code sandbox or interactive coding tools
- Backend feels unintuitive

**What users complain about:**
- Highest entry price in the market: $143/mo minimum (annual billing)
- 2025 price restructuring: Basic went from $149 to $179/mo, contacts cut from 10,000 to 2,500
- Aggressive feature-gating (affiliates, webhooks, API access require higher tiers)
- Additional 0.5-2% surcharge if using your own Stripe instead of Kajabi Payments
- Poor customer service with superficial, irrelevant generic responses
- Course features feel secondary despite being marketed as a course platform

**Pricing:** $69-$399/mo (various restructured tiers), previously $149-$399/mo

- No live sessions or cohort-based learning

- No ownership of student data/relationships

- No portfolio or project-based completion tracking
- No peer learning or collaboration tools

**What users complain about:**

- Constant algorithm changes reduce course visibility unpredictably

- Refuses to remove defamatory reviews

- Instructors lose control of pricing and student relationships

**Pricing:** Free to list; Udemy takes 37-67% of revenue depending on acquisition channel

## CROSS-PLATFORM GAPS: What NONE of Them Do Well

These are features that are missing or poorly implemented across ALL 10 platforms:

### 1. NO CODE EXECUTION OR SANDBOX ENVIRONMENTS
**Gap:** Zero platforms offer in-browser code execution, terminal emulation, or sandbox environments. For a coding education platform, this is a massive gap. Students must use external tools (Replit, CodeSandbox, VS Code) and manually switch contexts.

### 2. NO GITHUB INTEGRATION OR VERSION CONTROL
**Gap:** No platform connects to GitHub for assignments, project submissions, code review, or portfolio building. Students learning development tools have zero integration with the #1 tool they'll use professionally.

### 3. NO PROJECT-BASED PORTFOLIO SYSTEM
**Gap:** No platform helps students build a portfolio of completed projects that they can showcase to employers or clients. Certificates of completion are the ceiling -- there's no "show what you built" system.

### 4. NO PEER CODE REVIEW OR PAIR PROGRAMMING
**Gap:** No platform supports collaborative coding, peer code review workflows, or pair programming. The closest is Coursera's peer-graded essays, which is completely different from actual code review.

### 5. NO AI-ASSISTED LEARNING OR TUTORING (PURPOSE-BUILT)
**Gap:** While AI tutoring is emerging, none of these 10 platforms have purpose-built AI assistance integrated into the learning flow. No platform offers an AI that understands the course content and can help students when they're stuck on a specific lesson.

### 6. NO REAL-TIME COLLABORATIVE WORKSPACES
**Gap:** No platform provides a shared coding workspace where instructors and students can collaborate in real-time on actual code (not just chat).

### 7. POOR PROGRESS ANALYTICS FOR TECHNICAL SKILLS
**Gap:** Progress tracking across all platforms is binary: "completed" or "not completed." No platform tracks skill progression, competency levels, or mastery of specific technical concepts.

### 8. NO CLI/TERMINAL TOOL INTEGRATION
**Gap:** For teaching tools like Claude Code (which runs in the terminal), no platform has any way to integrate with or teach CLI-based workflows. All content is passive video/text.

### 9. NO ADAPTIVE DIFFICULTY OR PERSONALIZED PATHS
**Gap:** No platform dynamically adjusts lesson difficulty based on student performance. Everyone gets the same linear path regardless of their skill level.

### 10. NO "LEARNING BY DOING" VERIFICATION
**Gap:** Platforms verify that students watched a video or clicked "complete." None verify that students actually executed code, built something, or demonstrated competency through hands-on work.

## UNIQUE OPPORTUNITIES FOR BLOKSCHOOL

Given that BlokSchool teaches Claude Code, GitHub, and AI-assisted development, here are opportunities that directly align with its mission:

### TIER 1: HIGH-IMPACT DIFFERENTIATORS

**1. Embedded Code Sandbox / Terminal Emulator**
- In-browser terminal where students can practice Claude Code commands
- Pre-configured environments for each lesson
- No context-switching to external tools
- *Why it matters:* Zero competitors offer this. It's the #1 gap for coding education.

**2. GitHub-Integrated Project System**
- Students fork starter repos directly from lessons
- Automatic progress tracking based on git commits/PRs
- Project submissions via pull requests that instructors can review
- Student GitHub profiles become their portfolio
- *Why it matters:* Teaching GitHub without GitHub integration is like teaching cooking without a kitchen.

**3. AI Tutor Powered by Claude**
- Context-aware AI assistant that knows the specific lesson content
- Can help debug student code, explain concepts, give hints without giving answers
- Understands where students are in the curriculum
- *Why it matters:* BlokSchool literally teaches Claude -- having Claude as the tutor creates a meta-learning experience no one else can replicate.

**4. "Proof of Build" Completion System**
- Replace passive certificates with verified project portfolios
- Students demonstrate competency by building real things
- Public project showcase pages (like a developer portfolio)
- Shareable proof that's more valuable than a certificate
- *Why it matters:* Every platform gives certificates. None verify you actually built anything.

### TIER 2: STRONG DIFFERENTIATORS

**5. Live Collaborative Coding Sessions**
- Instructor and students share a live coding environment
- Built-in pair programming for student-to-student collaboration
- Screen sharing + code sharing in one interface
- *Why it matters:* Maven has live sessions but zero coding tools. Codio has coding tools but no community.

**6. Skill-Based Progress Tracking (Not Just Completion)**
- Track mastery across skill dimensions: Git proficiency, Claude Code fluency, prompt engineering, debugging, etc.
- Visual skill maps showing progression
- Pre/post assessments that measure actual learning
- *Why it matters:* All platforms track "did they finish?" -- none track "did they learn?"

**7. Challenge-Based Assessments**
- Timed coding challenges instead of multiple-choice quizzes
- Auto-graded based on code output, not answer selection
- Leaderboards for competitive learners
- Real-world scenarios (debug this code, build this feature, improve this prompt)
- *Why it matters:* Quizzes across all platforms are basic multiple-choice. Code challenges are completely absent.

**8. MCP / Tool Integration Playground**
- Interactive environment to experiment with Model Context Protocol
- Pre-built MCP server examples students can modify and test
- Connect to real APIs and services in a sandboxed environment
- *Why it matters:* MCP is cutting-edge and no platform teaches it with hands-on tools.

### TIER 3: COMPETITIVE ADVANTAGES

**9. Transparent, Creator-Friendly Pricing**
- Zero transaction fees at all tiers
- No student caps or product limits
- Flat, predictable monthly pricing
- *Why it matters:* Transaction fees and hidden costs are the #1 complaint across almost every platform.

**10. Community-Integrated Lessons**
- Discussion threads embedded directly within each lesson (not a separate tab)
- Students can ask questions in context, see others' questions, and help each other
- Instructor can pin answers and create FAQ from common questions
- *Why it matters:* Kajabi explicitly cannot do this. Most platforms separate community from courses entirely.

**11. Real-Time Code Review Workflows**
- Submit code for instructor or peer review
- Inline commenting on specific lines (like GitHub PRs)
- Review rubrics with actionable feedback
- *Why it matters:* Code review is a core developer skill. Zero course platforms teach or enable it.

**12. "Ship It" Project Milestones**
- Students deploy real projects at course milestones (not just "complete lesson 5")
- Integration with Vercel/Netlify for one-click deploys
- Public URLs for deployed student projects
- *Why it matters:* Deployment is a critical skill completely ignored by all platforms.
